Blackwall Lab Backup

Application personnelle de sauvegarde chiffrée.

Une solution conçue pour chiffrer localement des sauvegardes avec Restic et les transférer vers Google Drive via Rclone. Utilisation strictement personnelle, sans inscription publique.

Sure — Gestion financière

Instance privée auto-hébergée

Sure est une application open source utilisée par Blackwall Lab pour centraliser le suivi du patrimoine, des comptes bancaires, des investissements et des transactions personnelles.

L'application est hébergée sur une infrastructure privée. L'accès est réservé aux utilisateurs autorisés. Les connexions bancaires, notamment via Enable Banking, sont utilisées en lecture seule.
